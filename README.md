# USB-Hub
An SL2.1s based USB hub with USB C upstream, 3 USB C downstream, and 1 USB A downstream port. I made this project following the hackclub tutorial, with my own added touches.

## CAD
The case is made up of two parts. They are very similar with a few key differences. The top side features a 1mm thick, 1.5mm high lip. This press fits into the matching groove on the bottom half of the case. Through the force of these two pieces, the case will be held together. The two matching parts of the case allow the PCB to dropped into it without damaging ports. Each side features a diagonal element design of a different coloured print.
